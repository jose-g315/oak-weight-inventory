# oak-weight-inventory
Simple express inventory app. EJS for the views and PostgreSQL for the database. 

## Features
Users can browse the current inventory of weight plates, including each plate's price, quantity, manufacturer, and material. New weights can be added, and existing ones can have their price and quantity updated or be deleted. Manufacturers and materials can also be added, renamed, or deleted, as long as no weights are still using them.
